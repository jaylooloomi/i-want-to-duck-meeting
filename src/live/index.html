使用說明
線上會議：在 Codex／Claude Code 貼上會議連結，由 Agent 開啟記錄端。必要時自行登入、選帳號或等待主持人放行，程式會自動接續。
現場錄音：選擇「新增記錄」，確認收音方式後開始。瀏覽器麥克風錄音必須保持原分頁開啟。
英中／中英是原文顯示與翻譯的快捷設定，不會改變平台辨識語言。日文、德文等內容可用「全部原文」保留，再選擇翻譯語言。字幕更新時會節流送出即時暫譯，標示為持續更新；段落定稿後再以完整文字翻譯校正。需要網路與翻譯服務，可能有數秒延遲。
會後紀錄由已授權的 Agent 整理，不使用 Ollama。等待 Agent 不代表背景模型正在推論。差異核對為估計時間對齊，兩份原文均保留，須自行確認。
