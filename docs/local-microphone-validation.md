# 本機雙人逐字稿驗證

日期：2026-10-24（Asia/Taipei）

## 結果

使用兩段已知不同人的公開真人錄音，經 Chrome 虛擬麥克風輸入，跑過實際 AudioWorklet 收音、重採樣、HTTP 傳輸、Silero VAD、聲音特徵分群、Whisper 與即時逐字稿介面。辨識 API 與講者結果沒有使用假資料替換。

| 輪次 | 輸入 | 確認後的結果 |
|---|---|---|
| 1 | 第一人，正常音量 | 講者 A；最初片段先未確認 |
| 2 | 第二人，正常音量 | 講者 B；最初片段先未確認 |
| 3 | 第一人，音量降至 45% | 講者 A |
| 4 | 第二人，音量 65% 並加入輕微雜音 | 講者 B |
| 5 | 第一人，0.7 秒短句 | 講者未確認 |
| 6 | 第一人，再次發言，音量 80% | 講者 A |

逐段比對結果：5 段已確認文字、3 段未確認文字；已確認代號沒有交換，也沒有額外拆出第三人。
檢查同時核對文字結果及辨識器的講者決策，避免漏掉未生成文字的錯誤分群。
測試透過實際錄音與原始輸入的波形相關性校正時間，沒有假設模型啟動時間固定。

## 修正與回歸

- 不再依講者暫定邊界把語音切碎辨識：整段辨識，再依詞級時間戳配對講者，避免初次確認身分時漏掉文字。
- 新身分需兩個一致且互不重疊的片段；模糊、太短或證據不足時保持未確認。
- 四人樣本回歸維持 4 個已確認代號，沒有退回先前誤拆成 5 個的結果。
- 12 項 Python 回歸測試、3 項本機 API／瀏覽器收音測試與完整雙人、四人流程測試通過。
- 瀏覽器在收音尚未結束前就看到辨識文字；停止後麥克風停止、暫存清空、錄音與逐字稿保存。
- 測試頁面的請求全部留在 localhost；模型強制離線載入。
