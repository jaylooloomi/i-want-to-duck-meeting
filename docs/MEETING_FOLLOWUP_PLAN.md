# 會議後續功能實作順序

1. 整理模板：通用紀錄／專案週會／客戶訪談／技術討論。每場儲存，Agent待辦與匯出提示帶入；只改未來整理，不自動覆寫既有摘要。
2. 未確認事項與風險：統一Agent輸出規格，獨立待確認檢視，保留不確定性，缺負責人與期限不可補造。
3. 跨會議待辦：終態已整理會議、事項／負責人／期限／狀態／來源。重用每場完成狀態，篩選未完成／已完成／逾期與負責人；同名不同場次不自動合併。回會議與原文。

驗收：偏好保存／衝突與生成中鎖定；提示實際帶入Agent；待確認不混成決議；表格與舊版列表待辦；來源精確定位；跨場狀態隔離／持久化／版本衝突；API Origin及型別驗證；light/dark、390px與桌面、空資料、失敗重試、零Console/PageError。所有測試使用隔離虛構資料，不加入真人會議。
