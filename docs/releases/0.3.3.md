# Duck Meeting 0.3.3

Download **DuckMeeting-0.3.3-Setup-x64.exe** for Windows 10/11 x64. Finish recordings before upgrading. Existing meeting data is preserved.

## Changes

- Long transcripts now scroll within a bounded card instead of growing past the workspace and being clipped. Search/language controls and the recording player stay outside the scrolling area.
- Meeting-notes content has an explicit scrollbar rail with light/dark colors, retaining the fixed tab header and access to the bottom of long summaries and mail forms.
- The stylesheet URL is versioned so reloading the page fetches the updated scrolling styles.

No speech-model, backend or dependency changes. See the [QA report](https://github.com/jaylooloomi/i-want-to-duck-meeting/blob/v0.3.3/docs/qa/reports/release-0.3.3.md) for validation.

## Installation and known limits

Node.js is bundled. Chrome and the selected Agent are separate prerequisites; Claude integration requires the Claude CLI. The installer remains unsigned; Windows may show an unknown-publisher prompt. SHA256SUMS.txt verifies file integrity, not publisher identity.

The pre-existing BUG-ZIP-001 audio ZIP corruption issue remains unresolved. Preserve original WAV files directly. Existing BUG-004 skipped cases remain unaccepted. Synthetic UI/audio tests do not establish live meeting speech-recognition accuracy.

Validation: final complete regression **722 tests, 706 passed, 0 failed, 16 existing skips**. Isolated Windows install/upgrade/uninstall and data-preservation lifecycle passed.
