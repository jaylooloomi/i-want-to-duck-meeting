# Duck Meeting 0.3.0 — Windows installer

## Download and install

Download **DuckMeeting-0.3.0-Setup-x64.exe** below (Windows 10/11 x64). Setup includes Node.js and runtime dependencies; no Git, global Node or npm is needed. Choose Codex, Claude Code, or both. Chrome and the chosen Agent must be installed separately; Claude integration requires its CLI. Restart/reload the Agent after installation.

Windows installer is **unsigned**. Windows may display an unknown-publisher/SmartScreen warning. SHA256SUMS.txt verifies file integrity; it does not replace publisher signing.

## New

- Per-user Setup, desktop/Start-menu workspace shortcuts, speech-model preparation shortcut.
- Manual update check with consent, stable-release filtering and SHA-256 verification.
- Separate persistent meeting/model/profile directory, repair/upgrade data preservation and downgrade protection.
- Owned-integration cleanup on uninstall; data retained by default. Active recordings block upgrade/uninstall.
- Agent-authored local mail drafts after meeting notes; editor/copy/download and fixed-height scrollable body. No mailbox-create/send button; actual mail actions require your instruction and connected mail tools.
- Shared Traditional Chinese layout geometry across Chinese/English/Japanese/Korean, stable storage footer, preserved decision/action counts and plain advanced-menu labels.

## Data and updates

Program: `%LOCALAPPDATA%\Programs\DuckMeeting`. Data: `%LOCALAPPDATA%\DuckMeeting\data`. The installer edition uses localhost port 8792. Existing source-checkout meetings are not automatically migrated.

Use Start menu → Duck Meeting → Check for updates, or run a newer Setup. Remove through Windows Settings → Apps. Silent uninstall always preserves meeting data; interactive removal offers a separately confirmed data-deletion choice. Speech models/Python download when first needed; Prepare speech recognition shows progress.

## Validation and limits

Real Setup, isolated Codex/Claude installations, bundled-runtime HTTP workspace, repair, synthetic 0.2.99 → 0.3.0 upgrade, downgrade rejection and uninstall/data preservation were exercised on Windows without a global Node path. Unit tests validate updater selection, hostile assets/checksum rejection, ownership and active-recording guards.

The host was an existing Windows installation with isolated directories, not a clean VM. Fresh-VM model download, real provider mail sending, future-version interactive update prompts, SmartScreen reputation and ARM64 are not claimed. Private meeting data, sign-in profiles, tokens, recordings and models are not in the installer or source commit. Detailed evidence: `docs/qa/reports/windows-installer-030.md`.

Final regression: **704 tests, 688 passed, 0 failed, 16 existing skips**. Installer/updater/integrity/Korean follow-up: **8 passed**. [Detailed QA report](https://github.com/jaylooloomi/i-want-to-duck-meeting/blob/v0.3.0/docs/qa/reports/windows-installer-030.md).
