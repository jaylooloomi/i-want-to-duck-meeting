# Duck Meeting 0.3.2

Download **DuckMeeting-0.3.2-Setup-x64.exe** for Windows 10/11 x64. Finish recordings before upgrading. Setup preserves existing meeting data.

## Changes

- Starred transcript highlights now appear as gold pins on the recording waveform at the saved timestamps. Click a pin to seek; removal and reload remain synchronized. Pins require a playable recording and a known timestamp within its duration.
- The meeting-notes card has a bounded height and a vertical scrollbar for its active tab, while the tab header stays visible. Expanded mail selections and the lower fields/buttons remain reachable on desktop and mobile. Email body text retains its own scrollbar.
- Transcript search highlights literal matches in displayed original text, speaker names and translations. English matches ignore case; clearing the query removes highlighting. Special characters are treated as text, not HTML or regular-expression syntax.

## Installation and limits

Node.js is bundled; Chrome and the chosen Agent remain separate prerequisites. Claude integration requires the Claude CLI. The installer is unsigned and Windows may show an unknown-publisher prompt. SHA256SUMS.txt verifies file integrity, not publisher identity.

The existing BUG-ZIP-001 audio ZIP corruption issue remains unresolved: preserve original WAV files directly. Synthetic browser/audio tests validate these UI changes, not live meeting speech-recognition quality. No Ollama backend is used.
