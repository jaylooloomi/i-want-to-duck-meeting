# Duck Meeting v0.3.5

## 新增與修正 / Changes

- 智慧跟隨逐字稿：向上回看、搜尋或定位來源時暫停跟隨；新發言顯示返回最新按鈕，保留字幕／翻譯更新前的閱讀位置。
- 寬版逐字稿工具列依序為標題、搜尋＋快捷鍵＋語言選單、重點操作；窄版自動換行。
- 預設中英模式（原文中文、翻譯英文），修正部分語言參數意外關閉翻譯的情況；明確設定仍優先。
- 未完成會議／紀錄不再顯示誤導的待辦數量。
- 產品名稱右側顯示實際執行版本，版本號與名稱底部對齊。
- Smart follow pauses while reviewing/searching and preserves the visible paragraph through caption and translation updates. Click Jump to latest or manually scroll to the bottom to resume.
- Responsive transcript controls, corrected language defaults and unfinished-note counts, plus a runtime version label beside the product name.

## Download and upgrade

Download **DuckMeeting-0.3.5-Setup-x64.exe** below. Finish active recordings before running Setup. Existing installed-edition meeting data is preserved. Choose Codex / Claude Code integrations during installation. Python/speech models are prepared separately when needed; Chrome and the Agent host remain separately installed.

`SHA256SUMS.txt` contains the installer checksum. The installer remains unsigned; publisher signing / SmartScreen acceptance has not been established.
