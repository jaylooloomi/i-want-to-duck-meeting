# Duck Meeting 0.3.1

Download **DuckMeeting-0.3.1-Setup-x64.exe** below for Windows 10/11 x64. Run Setup to upgrade 0.3.0; installed meeting data is preserved. Finish recordings before upgrading.

## Changes

- Removed retired Ollama references from active runtime messages, four-language help text, current READMEs and Codex/Claude skill templates. The owning Agent still prepares meeting notes and mail drafts; no replacement summary backend was introduced.
- Fixed the sidebar language picker inheriting a 6px global select margin and a maximum width. Its edges and selected text now align with the footer controls in every locale and responsive breakpoint.

This patch does not change or uninstall the computer's Ollama application. It also includes the completed notes-source and mail-composition integration requested for this release.

## Notes-source and mail composition

- Decisions and actions can be linked to exact original transcript text, timestamp and speaker, reviewed, located in the transcript, and replayed when audio/time is available.
- Unknown or changed sources remain unlinked; version checks preserve edits and prevent stale links. Original notes and transcripts are retained.
- Mail content can be selected, previewed, applied to the body and undone; manual text is not replaced by checkbox selection alone. No mailbox creation or sending is automatic.

## Installation notes

Node.js is bundled. Chrome and the chosen Agent are separate prerequisites; Claude integration needs the Claude CLI. Existing Agent conversations may need a skill/plugin reload. Speech models download when needed.

The installer remains **unsigned**; Windows may show an unknown-publisher/SmartScreen prompt. SHA256SUMS.txt is an integrity check, not publisher signing. Data and models remain under `%LOCALAPPDATA%\DuckMeeting\data`. Use the Start-menu update shortcut or download this Setup manually.


Known pre-existing issue: full-session ZIP exports can contain corrupt audio entries (BUG-ZIP-001). Preserve original WAV files directly. The issue was independently reproduced and is not repaired by this release.
