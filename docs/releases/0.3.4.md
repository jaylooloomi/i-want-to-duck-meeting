# Duck Meeting 0.3.4

Download **DuckMeeting-0.3.4-Setup-x64.exe** for Windows 10/11 x64. Finish recordings before upgrading; existing meeting data is preserved.

## Changes

- Click linked decision/action text, or press Enter, to clear transcript filters, locate its exact source and temporarily highlight the paragraph. Existing source-review controls remain available.
- Source highlighting spans the transcript content width while preserving text alignment and leaving the scrollbar clear.
- Source navigation no longer scrolls the hidden outer workspace and clips the card header.
- Action text is independent of completion: only the checkbox toggles completion. Unlinked text has no navigation behavior.
- Codex/Claude summary instructions now explicitly require original source quote/time for decisions/actions. Links are established only after exact, unique transcript matching; unknown evidence stays unlinked. Historical meetings are not automatically rewritten.

## Installation and known limits

Node.js is bundled. Chrome and the selected Agent are separate prerequisites; Claude integration requires the Claude CLI. Reload skills/plugins or use a new Agent conversation after upgrading to pick up new instructions. Agent operation still depends on the host; a finished summary does not guarantee all source links were confirmed.

The installer remains unsigned. SHA256SUMS.txt verifies integrity, not publisher identity. Existing BUG-004 skips and BUG-ZIP-001 (corrupt audio in full-session ZIP exports) remain; preserve original WAVs directly. Synthetic UI/audio tests do not establish live meeting ASR quality.

See the [QA report](https://github.com/jaylooloomi/i-want-to-duck-meeting/blob/v0.3.4/docs/qa/reports/release-0.3.4.md).

Validation: across the complete suite and targeted reruns, **710 cases verified passing, 16 existing skips** (726 unique cases). Initial timing failures and test-only synchronization corrections are detailed in QA; the final audio/integrity rerun passed 14/14. Source/mail integration and isolated installer lifecycle passed.
