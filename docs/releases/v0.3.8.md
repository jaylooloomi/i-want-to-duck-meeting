# Duck Meeting v0.3.8

- View recent captions and stop recording from the dedicated Google Meet or Teams window. Google Meet also supports pause and resume.
- Compare platform captions with an existing audio transcript using `crosscheck <ID>`. Differences such as numbers, decimals, negation and dates are flagged for review.
- Use `report <ID>` to produce a separate draft or validate quotations in a reviewed report. The existing workspace, Agent summaries, tasks and email drafts remain available.

Download `DuckMeeting-0.3.8-Setup-x64.exe` for Windows 10/11 x64. Run Setup to upgrade. Meeting data stays in its separate local directory. `SHA256SUMS.txt` contains the installer checksum.

Recording controls were tested with a simulated Meet session in Chrome. This release has not been verified in live Google Meet or Teams calls.

---

- 專用 Meet／Teams 視窗可查看近期字幕、結束記錄，Meet 另可暫停與繼續。
- 使用 `crosscheck <ID>` 對齊字幕和既有錄音轉錄，提示數字、小數、否定詞及日期差異。
- 使用 `report <ID>` 產生獨立審閱草稿或驗證引文。正式會議紀錄、待辦和郵件仍使用新版工作台。

下載 `DuckMeeting-0.3.8-Setup-x64.exe` 並執行安裝，可升級 Windows 10/11 x64 版本。會議資料保留於獨立的本機資料目錄。可用 `SHA256SUMS.txt` 核對檔案。會議控制已用 Chrome 模擬 Meet 驗證，本版未做真人 Meet／Teams 驗收。
