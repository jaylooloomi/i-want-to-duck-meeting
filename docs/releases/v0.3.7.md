# Duck Meeting v0.3.7

This Windows installer bundles the workspace fixes previously available only in the local working copy.

- Fix dark-mode mail section checkboxes and inconsistent disabled controls.
- Fix blank main content at tablet/short window sizes; add responsive breakpoint regression checks.
- Unify close icons, form fields, mail actions and source controls; fix transcript reading width and feedback overlapping playback.
- Include meeting templates, unresolved questions and cross-meeting task tracking.
- Add natural Chinese tutorial narration, theme-aware playback controls and stop after one play.
- Add one-command Playwright UI checks with isolated fixtures and retained failure evidence.

Install `DuckMeeting-0.3.7-Setup-x64.exe` from this release. Existing meeting data remains in its separate data directory. Verify **v0.3.7** beside Duck Meeting after Setup and refresh the workspace.

Validation: 37 recent UI tests and 26 unit/install-contract tests passed. The prior complete 168-case run and related reruns are documented in the repository. The newly added responsive matrix passed 16 cases and the scrolling/player checks passed 10 cases.
