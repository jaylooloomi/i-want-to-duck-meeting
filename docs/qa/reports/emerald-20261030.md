## 已完成的功能

- 三張來源卡與狀態：音檔、逐字稿、Agent 紀錄；沒有來源時維持空／等待狀態。格式、時長、已記錄發言者與段數都由實際檔案及資料推導。
- 左側會議清單、平台標記、搜尋、日期、封存、重新命名、匯出、設定／說明；日期精簡，完整起訖時間仍可由提示查看。
- 常駐逐字稿搜尋、英中／中英與翻譯語言、未定稿暫譯；Ctrl/Cmd+K 搜尋會議，非輸入欄位中 Ctrl/Cmd+F 搜尋逐字稿。
- 逐段星號與操作選單：複製原文、標記／取消、回聽本段；原始文字與音訊不被改寫。時間顯示相對錄音起點，絕對時間保留在提示。
- 真實 PCM 波形、播放／暫停、Range 定位、混合／麥克風／遠端音軌、速度／音量，以及放大／按鈕或 Escape 還原。
- Agent 紀錄卡片、摘要／決議／待辦、複製／下載；表格勾選完成保存在本機 `action-items.json`，不重寫原 Markdown、不補造責任人或期限，ZIP 包含狀態檔。
- 待辦寫入驗證精確場次、同源、布林值、合法鍵、現行摘要版本；拒絕未知／過期項目。原子保存、重複列區分、跳脫直線與巢狀行動標題、異常保存檔回復均有測試。
- 來源差異檢視與回聽；逐字稿來源視窗／閱讀版 TXT 下載；缺少獨立轉錄時不假裝核對成功。
- 本機會議檔案大小與磁碟可用空間，忽略符號連結、限制掃描量並快取，隨會議狀態及定期更新；沒有虛構固定配額。

沒有供應真實頭像時使用姓名縮寫。音檔依實際 PCM WAV 顯示，不假裝 MP3；沒有準確率保證或虛構出席名單。不使用 Ollama，也沒有新增套件。

4. 新版錯把活動／停止／段數狀態隱藏：搬回標題資訊列；FE-01、FE-03、E2E-01、E2E-06 再驗證通過。
5. 待辦保存檔 null／破損、過期版本：安全回復、版本校驗與精確項目鍵；原始紀錄不被覆寫。

## 本機與驗收限制

- 已確認沒有進行中的會議後，僅重啟獨立本機 viewer。新版 CSS、SVG 與儲存 API 實際 HTTP 200；[開啟或重新整理工作台](http://127.0.0.1:8791/)即可使用。
- **16 項既有 BUG-004 嚴格 Console／HTTP 錯誤限制維持跳過**，不計入通過，也未修改 guard。
- 本次使用受控資料與合成音訊，不加入真人會議、不使用私人錄音。UI／PCM／API 行為通過不等於已重新驗證真人 ASR、Google／Teams 放行、翻譯服務可用性或 Agent 輪詢延遲。
