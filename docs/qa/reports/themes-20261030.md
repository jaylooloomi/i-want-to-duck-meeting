## 操作

刷新本機工作台後，使用左下角「深色／淺色」，或「設定 → 外觀風格」。白色延續翡翠極簡，暗色採深藍黑底、藍色按鈕、青色波形及紫色 Agent 標示；卡片、輸入欄位、表格、播放器、來源核對、錄音設定與對話視窗均有對應配色。

偏好保存在目前瀏覽器的 `duck-meeting:theme`，啟動時在 CSS 前讀取。同一本機網址的其他分頁會同步；無效值回到白色。瀏覽器禁止儲存時仍能切換並顯示無法保存提示。切換不導航、不重新載入媒體或改變目前會議。
