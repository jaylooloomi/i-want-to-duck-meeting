# International layout follow-up — 2026-10-30

## Observed problems and replacement layout

The first localized screenshots retained Chinese-sized fixed controls: selected English option text was truncated, Korean source labels split into individual glyphs, and the footer language label wrapped inconsistently. Functional locale tests alone had not verified these geometry failures.

The revised layout gives non-Chinese interfaces a 260px desktop sidebar (240px at tablet widths), a full-width stacked language setting and stable tool/storage groups. The transcript header uses three deliberate grid rows: title/presets, full-width search, and two fluid language fields. Notes use separate title, action and tab rows. Source rows now use two lines for human label and filename, with stable duration and action columns. Mobile stacks source status cards and keeps controls within the viewport. Color palettes share the same layout.

No recording/transcription logic or original meeting content was changed. Screenshots use synthetic meeting data; Chinese meeting titles and notes deliberately retain their source text.
